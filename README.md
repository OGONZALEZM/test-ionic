This is a test app built with Ionic that supports Bluetooth devices. I used the @capacitor-community/bluetooth-le library, which was already included in the project. 
I added methods to check Bluetooth status, scan for devices, and connect or disconnect from them. 
I implemented support for a Bluetooth printer to demonstrate the success flow, I included a video showing the app running on a real device. 
Additionally, I started working on unit tests, though they are still a work in progress.
